# Texto exacto antes de registrar

La regla: antes de escribir en un registro canónico (glosario, decisiones, preferencias, Terminología Farlopa), mostrar el texto exacto que se va a asentar y esperar el visto bueno.

**El matiz que importa:** un "sí" a *"¿lo registro?"* aprueba la **acción** de registrar, nunca el **contenido**. Lo que el usuario no leyó, no lo ratificó. Por eso lo que se muestra es el texto literal, no un resumen de lo que se va a poner.
